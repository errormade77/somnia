# Иконки кнопок настроек

| Файл | Карточка | Образ |
| --- | --- | --- |
| `storage.svg` | Хранилище | Сфера с заполненной нижней половиной |
| `retention.svg` | Срок хранения | Песочные часы |
| `gesture.svg` | Жесты | Прямой крест: четыре активных направления и касание |
| `style.svg` | Стиль записи снов | Две звёздочки |
| `saving.svg` | Характер сохранения снов | Сердце |
| `matrix-12x12.svg` | Исходная сетка | Все 144 точки |

Все изображения имеют `width="24"`, `height="24"`; исходная матрица — 105 × 105 px.
Исходная сетка — 12 × 12 точек: диаметр 6, расстояние между краями соседних
точек 3, шаг центров 9. Координаты центров: `3 + 9 × столбец` и
`3 + 9 × строка`, где индексы идут от 0 до 11. Радиус каждой точки — 3.

Фигуры состоят только из кругов в узлах этой матрицы. `fill="currentColor"`
позволяет использовать SVG непосредственно с цветом текста либо как CSS-маску.

Битмапы находятся в `scripts/generate-orbit-icons.mjs`: для каждого изображения
записано двенадцать строк по двенадцать символов. `1` включает точку, `0` оставляет место
пустым. Для повторной генерации из корня проекта:

```sh
node scripts/generate-orbit-icons.mjs
```

У креста пять точек на каждом луче и одна в центре: используется подмножество
11 × 11 внутри матрицы 12 × 12. Для оптической центровки его `viewBox` —
`-4.5 -4.5 105 105`; координаты точек остаются в исходной сетке.
У остальных файлов `viewBox="0 0 105 105"`.
