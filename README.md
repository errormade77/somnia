# Somnia — Dream Recorder

Интерактивный прототип хранилища снов и управления устройством Somnia по [Figma, узел 77:6297](https://www.figma.com/design/DFqWKzbzW9dgfr5QbckU3S/somnia?node-id=77-6297). Работает локально и собирается в статический сайт для GitHub Pages; серверная часть для опубликованной версии не требуется.

## Запуск

Рекомендуется Node.js 22.12 или новее (версия, поддерживаемая Orbloom). При первом запуске установите зависимости из lockfile:

```sh
npm ci
npm run dev
```

Открыть http://127.0.0.1:5173. Для другого порта: `PORT=3000 npm run dev`.

## Статическая сборка и GitHub Pages

```sh
npm run build
```

Сборка появляется в `dist/` и рассчитана на базовый путь `/somnia/`. Создаются главная `/somnia/` и отдельный `settings/index.html` для прямого открытия `/somnia/settings/`. Пути к модулям, стилям, шрифтам, видео и навигации переписываются автоматически; сборка проверяет наличие ресурсов. Параметры оформления включаются в артефакт из текущего `site-settings.json`.

Для публикации в корне домена:

```sh
npm run build:root
```

Эта команда также создаёт `dist/`, но с базовым путём `/`. Для другого префикса можно вызвать `node scripts/build-site.mjs --base /another-project/`. Публиковать нужно содержимое `dist/`; Node.js нужен только для локальной разработки и сборки. Live reload и обращения к локальным API в опубликованную версию не входят.

Workflow [`.github/workflows/pages.yml`](.github/workflows/pages.yml) собирает сайт на Node.js 22 и публикует артефакт через GitHub Actions. Чтобы подключить публикацию:

1. Поместите исходники проекта в репозиторий GitHub с основной веткой `main`.
2. В **Settings → Pages → Build and deployment → Source** выберите **GitHub Actions**. [Инструкция GitHub](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).
3. Отправьте изменения в `main` или вручную запустите **Deploy GitHub Pages** во вкладке Actions. Workflow получает базовый путь из конфигурации Pages, выполняет тест сборки и публикует `dist/`.
4. После успешного задания `deploy` откройте адрес из окружения `github-pages` или раздела Pages репозитория.

Адрес сайта определяется подключённым репозиторием и настройками Pages; конкретный аккаунт и URL в проекте не зафиксированы.

## Страницы и виджеты

Главная `/` соответствует [Figma, узел 46:6125](https://www.figma.com/design/DFqWKzbzW9dgfr5QbckU3S/Dream-Recorder?node-id=46-6125): логотип и аватар в верхних углах, устройство диаметром 111 px внизу слева, отступы от краёв 12 px. Рядом расположены заряд, кнопка питания, изображение девайса и статус `somnia-01`. Это общие виджеты обеих страниц; изображение девайса и плашка `somnia-01` открывают настройки. Клик по устройству открывает `/settings` с увеличением и перемещением того же шара к карточкам. Логотип возвращает на главную с обратным переходом. Прямые ссылки, перезагрузка и история браузера поддерживаются; системное ограничение движения отключает трансформ. На узком экране нижний ряд пропорционально уменьшается.

`home-preview.js` выбирает случайный сон из существующего видеокаталога при каждом входе на главную с включённым девайсом, без повторения предыдущего ролика. Сон воспроизводится без звука по кругу через общий слой стекла и матовости. Поверх него расположены часы Doto и оригинальная белая тень из Figma. Время берётся из часов компьютера в его часовом поясе, формат — ЧЧ:ММ; обновление привязано к началу минуты и возобновлению вкладки. При переходе в настройки видео останавливается; при скрытии вкладки также приостанавливаются видео и таймер. Скорость анимации и ограничение движения учитываются.

Кнопка «выкл.» скрывает сон и часы малого девайса, оставляя пустую стеклянную оболочку, и останавливает его видео и таймер. Она становится круглой с красным индикатором и подписью «вкл.»; повторный клик возвращает воспроизведение и зелёный индикатор. Состояние сохраняется в localStorage. Большая галерея и превью настроек работают независимо от этой кнопки.

SVG-фавикон `assets/favicon.svg` использует точечный логотип: чёрный в светлой теме браузера и белый в тёмной. При локальной разработке HTML, CSS и JavaScript обновляются в браузере после сохранения файлов.

В обновлённом экране настроек общий хэдер содержит логотип и аватар. Под логотипом — круглая кнопка возврата на главную (52 × 52, слева 12 px, сверху 72 px). Статус подключения расположен в нижнем виджете, дополнительная подпись под большим шаром убрана. Карточки срока хранения и стиля имеют высоту 168 px и отступ 44 px перед переключателями; карточка сохранения — минимум 224 px с ростом по содержимому. Иконка возврата экспортирована из Figma. Строка «настройки хранилища / 127 снов» информационная, без hover, стрелки и открытия окна. Тень под часами обновлена по узлу 46:6154: белый эллипс 81 px, SVG вместе с мягкими краями — 117 × 117.

Переход устройства между страницами проходит по дуге с отдельной пружинной динамикой масштаба: увеличение слегка запаздывает, выходит за конечный размер и мягко стабилизируется. Раскрытие занимает 920 мс, возврат — 820 мс. На время перелёта внутренние видео и атлас девайса удерживают последний кадр, а затем продолжают воспроизведение. В поддерживаемых браузерах кадры однократно проходят через ту же линзу в переиспользуемых canvas-буферах и плавно смешиваются как готовые текстуры; цифры, часы и иконки остаются отдельным резким слоем. Эффект заранее прогревается в idle. Если кадр ещё не готов, Canvas SVG-фильтр недоступен или пользователь меняет настройку карточки или питание во время полёта, сохраняется нативный вариант. Фильтр стекла и compositor-слои не сбрасывают настройки. Главная галерея остаётся живой. Нативные Web Animations меняют только трансформы; новая навигация начинается из текущей видимой позиции без скачка. Изменение размера окна завершает полёт в новой геометрии. Ограничение движения и отключённая анимация пропускают полёт.

## Реализация

- Эталонный размер макета: 1440 × 1024; колонка карточек справа: 467 px, промежутки — 12 px.
- Центр шара находится на половине высоты экрана +0.5 px. Кнопка 5 и верх первой карточки при открытии лежат на оси 50% высоты экрана минус 7 px. Диаметр шара — 415 px с адаптацией к доступному месту. Заряд вынесен в нижний левый угол.
- Пять кнопок расположены с равными интервалами по длине четверти эллипса. Две крайние позиции сохранены из Figma: (720, 234) и (453, 505); промежуточные вычисляются в `settings-geometry.js`.
- Клик по иконке плавно совмещает центр соответствующей карточки с осью шара. При обычной прокрутке активируется ближайший центр карточки. Никаких sticky-эффектов, сжатия или размытия карточек; ручной скролл может прервать переход. Стрелки и Home/End работают с клавиатуры на кнопках дуги.
- Активная карточка и увеличенная кнопка синхронизированы. Наведение, фокус и клик внутри карточки также активируют её. Хранилище показывает в шаре показатель 85.2 gb, подпись «осталось» и сетку круглых превью снов. Срок хранения показывает выбранное число дней и исчезновение снов. Карточка жестов показывает выбранный жест и примеры действий со снами; стиль записи — натуральное или абстрактное видео. Характер сохранения: «все» показывает четыре круглых сна в сетке 2 × 2, «приятные» — салют (dream-08), «спрашивать» — бассейн с шариками (dream-09) и текст вопроса из Figma 52:7538. Превью используют общее стекло и матовость, неактивные видео останавливаются. Контент размещён в `#device-preview` с ключом активной карточки `data-active`.
- Оригинальные SVG экспортированы из Figma и сохранены в `assets/`.
- Inter 400/500 и Doto 600/700/900 с осью ROND=100 загружаются локально.
- Все пять секций доступны при прокрутке, включая нижние блоки за пределами первого экрана Figma.
- Переключатели, назначение действий жестам и справки работают. Настройки сохраняются в localStorage.
- Показатели устройства и хранилища демонстрационные, соответствуют макету; подключения к физическому устройству нет.
- На узких экранах шар с дугой занимает верхнюю область, а карточки центрируются в оставшейся части экрана. Пять жестов без пустых слотов выровнены по центру карточки; при недостатке места круги и иконки пропорционально уменьшаются.

## Лайв-превью

Шар состоит из прозрачной CSS-оболочки и отдельного контейнера для контента. Космический WebGL-рендерер отключён. Из [Orbloom](https://github.com/rickybharti/orbloom), версия `0.1.0` (MIT), сохранены стили формы/парения и перенесены формулы краевого преломления и смещения RGB-каналов. Они применяются к живому наполнению через SVG-фильтр в `orb-refraction.js`: видео и сетка проходят через общую линзу. Цифры и точки жестов остаются поверх оптического слоя. Сила преломления задана значением `orb.glass` в defaults сборки. Карта смещений подготовлена заранее в assets/orb-displacement.png. Линза стабильна: живое преломление создаётся движением самих видео, без повторного изменения SVG-фильтра каждый кадр. Каждая сцена сохраняет один и тот же фильтр на всём протяжении crossfade, включая уходящий сон. Фильтр не переносится между контейнерами при навигации; opacity меняется снаружи него. Цифры, крест, часы и белые тени вынесены в отдельную плоскость поверх стекла. Все ресурсы доступны локально; временные текстуры перелёта содержат только медиа, без интерфейсной графики. Лицензия исходного эффекта — `assets/Orbloom-LICENSE.txt`.

Превью хранилища и срока хранения обновлено по [Figma, узел 77:6297](https://www.figma.com/design/DFqWKzbzW9dgfr5QbckU3S/somnia?node-id=77-6297). `dream-storage-sphere.js` использует те же 49 сферических позиций, что и галерея главной, с перспективным сжатием кругов у края. Это неподвижная раскладка с живыми снами, без управления, отдельного WebGL или собственного RAF. Проекция и порядок глубины рассчитываются один раз. Десять снов берутся из общего атласа 640 × 256 при 20 fps (128 × 128 на сон), поэтому дополнительный видеодекодер не нужен. Холст обновляется только с видеокадром, мягкая маска подготовлена один раз, исчезновение и преломление сохранены. На шаре показан остаток ёмкости: 85.2 gb / осталось. Цифры и подписи масштабируются относительно дизайн-сцены 415 px. В баре карточки сохранено живое перетекание, палитра обновлена на розовый #ff6bb7, лавандовый #b0b0e3 и голубой #caebfd.

Превью срока хранения использует ту же сетку и преломление ([Figma, узел 39:5305](https://www.figma.com/design/DFqWKzbzW9dgfr5QbckU3S/Dream-Recorder?node-id=39-5305)). Число соответствует выбору 7 / 14 / 30 дней. SVG `assets/retention-*.svg` содержат исходные контуры Doto Bold, каждый путь — отдельная точка. Сны и точки исчезают по очереди сверху вниз на общей временной шкале: показ 0.9 с, исчезновение 4.3 с, пауза 0.4 с, восстановление 0.65 с; полный цикл 7.2 с при скорости 1×. Скорость меняется без сброса прогресса. Смена срока перезапускает пример, уход с карточки отменяет анимацию и восстанавливает сетку. При отключённой анимации отображается полный неподвижный кадр. Это демонстрация: сами записи не удаляются.

Превью жестов соответствует [Figma, узел 34:4483](https://www.figma.com/design/DFqWKzbzW9dgfr5QbckU3S/Dream-Recorder?node-id=34-4483). Оригинальные SVG-точки увеличиваются волной от центра в направлении выбранного жеста, синхронно в карточке (58 px) и шаре. В шаре используется SVG-контейнер 263 × 266.812 px, а расстояния точек от центра сокращены до 85% исходных: крест компактнее, размер самих точек не уменьшается. Касание увеличивает центральную точку. После завершения последней точки выдерживается пауза 80 мс, затем проигрывается назначенное действие: следующий/предыдущий сон листаются в противоположных направлениях, пауза уменьшает сон до 68% диаметра шара, воспроизведение разворачивает его на весь шар, громкость отображается кольцом из 48 точек по 4 × 4 px с отступом 16 px от внешнего края сферы. Точки последовательно чернеют или гаснут по часовой стрелке от верхней позиции: пример начинается с 50% и доходит до 80% или 30%. Все примеры зациклены: результат ненадолго задерживается, пауза/воспроизведение/громкость плавно возвращаются в исходное состояние, затем снова запускается жест. Пауза между крестом и действием сохраняет 80 мс при любой скорости. Повторный выбор действия запускает пример заново. При уходе с карточки или скрытии вкладки анимации останавливаются; ограничение движения показывает конечное состояние без анимации.

В жестах используются те же 10 видеоснов из `assets/dreams/catalog.js` и мягкая круглая маска из Figma. Три переиспользуемых слота хранят текущий сон и соседей; при перелистывании элементы меняют позицию, сохраняя текущий кадр видео. Одновременно воспроизводятся текущий и входящий сон, остальные стоят на паузе. До открытия карточки полные ролики не загружаются. Пауза/воспроизведение управляют самим видео, а не только размером круга.

Пользовательские MP4 из папки `Dreams` обработаны скриптом `scripts/prepare-dreams.py`: центральный кроп 1:1, 512 × 512, H.264 / yuv420p, 24 fps, CRF 26 с ограничением битрейта, faststart. Ролики сохранены целиком, превью без звука. Исходные файлы не изменялись. Общий объём исходников — 52.65 МБ, подготовленных видео, постеров и атласа — 13.25 МБ. Для повторной подготовки: `python3 scripts/prepare-dreams.py /path/to/Dreams --ffmpeg /path/to/ffmpeg`. Каталог генерируется автоматически. Локальный сервер отдаёт MP4 потоково с поддержкой HTTP byte ranges (206/416), чтобы браузер загружал и перематывал нужные участки.

Под цифрами, подписями и крестом жеста находится мягкая белая тень из [Figma, узел 44:5718](https://www.figma.com/design/DFqWKzbzW9dgfr5QbckU3S/Dream-Recorder?node-id=44-5718). Обновлённый оригинальный SVG `assets/figma-sync/orb-graphic-shadow.svg` сохранён локально: эллипс 274 px, Gaussian blur 52 px, итоговый размер 482 × 482. Тень масштабируется вместе со сферой и лежит над видеоснами, под графикой, вне слоя преломления. В сроке хранения исчезает и возвращается вместе с подписью «дней». Тень часов на главной остаётся отдельным ассетом узла 46:6154.

В карточке стиля записи `style-preview.js` переключает два зацикленных ролика: натуральный `dream-10.mp4` с девушкой на лугу и его абстрактную версию `running-abstract.mp4`. Абстрактные ленты, округлые формы и градиенты используют палитру и движение исходного видео; они подготовлены заранее, поэтому браузеру не нужно рассчитывать их каждый кадр. Скрипт `scripts/prepare-abstract-dream.py` требует NumPy, Pillow и FFmpeg: `python3 scripts/prepare-abstract-dream.py --ffmpeg /path/to/ffmpeg`. Результат — 512 × 512, H.264, 24 fps, 5 секунд, около 127 КБ. Переключение сохраняет время воспроизведения, к обоим режимам применяются стекло, матовость и скорость анимации. Загружается только выбранный ролик; неактивное видео, скрытая вкладка и отключённая анимация ставят воспроизведение на паузу.

## Настройки сборки

Внешний вид сфер, матовость, скорость анимаций и прокрутка зафиксированы в `site-settings.json`. При сборке файл проверяется и преобразуется в `dist/assets/site-defaults.js`; `orb-settings.js` только читает этот модуль и применяет значения. Для изменения общего оформления нужно обновить исходный JSON, пересобрать сайт и опубликовать новую сборку. Редактора параметров в интерфейсе нет: двойной клик и `Alt/Option + P` ничего не открывают. Опубликованный сайт не записывает параметры оформления на сервер.

Раздел `orb` определяет размер, преломление, матовость, блики, парение, скорость и размер точек жеста. Матовость рассеивает видео после преломления, добавляет лёгкую молочную дымку и смягчает блики; цифры и точки остаются резкими. `gallery` задаёт размытие краёв, силу растворения и матовость снов в большой галерее. `scroll` задаёт сглаживание, скорость и плавность остановки для карточек и зума галереи. Системное ограничение движения учитывается.

`smooth-scroll.js` использует затухание по реальному времени, отменяет движение при ручном вмешательстве и смене страницы, сохраняет нативную прокрутку внутри окон и на сенсорных экранах. Карточки остаются в обычном потоке; кнопки дуги центрируют выбранную карточку по оси устройства. При ограничении движения или отключённой анимации сглаживание отключается.

Это отдельные параметры от интерактивных настроек устройства: срок хранения, стиль, характер сохранения, назначения жестов и питание по-прежнему меняются на сайте и сохраняются в localStorage конкретного браузера.

## Переходы и подсветка

Хэдер закреплён и прозрачен: карточки видны под ним при прокрутке. При появлении настроек пять кнопок с иконками раскрываются веером от первой позиции по общей эллиптической дуге. Каждая увеличивается с мягкой пружиной: 640 мс, начальная задержка 220 мс и каскад с шагом 75 мс. При выходе кнопки сворачиваются обратно от пятой к первой: 460 мс, каскад 55 мс. Быстрый разворот продолжает движение из текущих позиций. Нажатие на раздел не обрывает веер. Размеры anchors постоянны: отдельно масштабируются фон 52–72 px и иконка 24–28 px, поэтому hover-холст не пересоздаётся. Изменение размера экрана или отключение движения завершает анимацию.

Проверка синтаксиса: `npm run check`. Автоматические проверки: `npm test`. Тест статической сборки запускается отдельно командой `node --test test/build-site.test.mjs`; он проверяет ресурсы и маршруты для корня и подпапки.

Кнопки и табы подсвечиваются при наведении и фокусе с клавиатуры эффектом [Voice Glow](https://libraries.dev/voice). В `hover-glow.js` оригинальный визуальный движок (MIT, Jakub Antalik) управляется уровнем наведения: цветные слои поднимаются от нижней кромки и плавно затухают при уходе курсора. У обычных кнопок подсветка находится внутри их формы, под текстом и иконками. У табов это единый фон всего переключателя: свет следует за наведённым табом, проходит под прозрачными соседями и перекрывается выбранным белым табом. На выбранном табе свечение продолжает работать за белой кнопкой; у остальных выбранных кнопок эффект не запускается; геометрия интерфейса сохраняется. Активны только текущий элемент и коротко затухающие предыдущие. При смене страницы, скрытии вкладки или отключении анимации работа останавливается. Голосовой ввод не подключён. Движок хранится локально в `assets/voice-glow/engine.js`; исходники, лицензия и команда повторной сборки указаны в `scripts/vendor/voice-glow/README.md`.

Бар хранилища восстановлен по исходному дизайну: заполнение 195 × 48 px при ширине дорожки 442 px, отступ 8 px, скругление 16 px и размытие 10 px. Сохранено плавное переливание, цвета взяты из светлой палитры Voice Glow. Фон совпадает с фоном переключателя срока хранения. Анимация приостанавливается за пределами экрана, на главной и при отключении движения. Свечение табов плавно перемещается внутри общего фона, включая наведение на выбранный таб за его белой поверхностью; события hover, фокуса и выбора объединяются в одно обновление кадра. Порядок жестов: влево, вправо, вверх, вниз, касание.

Белая подложка сегментированных переключателей перемещается за 540 мс с пружинным замедлением, без изменения формы и размера. Повторный выбор во время движения продолжает анимацию из текущего положения. При отключении движения и изменении размеров выбранная подложка устанавливается сразу. У кнопок действий фон, цвет и радиус плавно меняются одновременно с затуханием исходящего hover. Градиент хранилища использует полупрозрачные розовые, сиреневые и голубые слои с небольшим тёплым акцентом.


## Производительность

Хранилище и режим «все» используют общий видеодекодер атласа и по одному холсту на сцену. Разрешение холста подстраивается под размер шара, ограничено 1.5× и 640 px. Анимация исчезновения рисуется в том же холсте с сохранением порядка и тайминга точек/подписи. Невидимые сцены скрываются после перехода, неактивные видео стоят на паузе.

Размеры эффекта Voice Glow кэшируются через ResizeObserver: драйвер не вызывает синхронный layout после изменения CSS-переменных. При уходе курсора последний кадр свечения затухает через opacity без фонового рендера. Изменение одной группы настроек не пересчитывает остальные переключатели и не перезапускает соседние превью.

Аватар для интерфейса — assets/home-avatar-small.png (210 × 280, около 56 КБ вместо 6 МБ). Оригинал сохранён. Локальный сервер поддерживает ETag, Last-Modified, 304 и If-Range для повторного использования ресурсов и перемотки видео без полной повторной загрузки.

Для воспроизводимого замера открыть /settings?perf и нажать «Замерить 8 секунд». После секунды прогрева диагностическая панель показывает FPS, p95/максимальное время кадра, кадры длиннее 25 мс, длинные задачи и количество изменений SVG-фильтра. Во время замера можно переключать карточки, табы и прокручивать страницу. Кнопка «Проверить переходы» выполняет шесть переходов между главной и настройками, отдельно показывая частоту и p95 кадров полёта. На обычном адресе диагностический модуль не загружается. Показатели зависят от браузера, экрана и фоновой нагрузки.

## Сферическое хранилище на главной

Сфера перенесена из исходного `SphereGallery3d_v2` демо https://vast-author-374088.framer.app/. Пользователь подтвердил разрешение автора на перенос вне Framer. Оригинал и описание адаптации — `scripts/vendor/sphere-gallery/`.

Сохранены 49 позиций демо, геометрия Фибоначчи с полюсами, ориентация плоскостей к центру, камера FOV 45°, desktop/mobile радиусы 5 / 2.2, размеры и промежутки. GSAP воспроизводит исходный разлёт, каскад масштаба, приближение камеры и торможение начального вращения; начальный диаметр обновлён до 415 px по макету (с адаптацией на узком экране). Перетаскивание, инерция и автоматическое вращение используют формулы оригинала. По последующей просьбе пользователя зум колёсиком и pinch подключены к общему `createScrollMotion`: скорость, плавность, переключатель и смена направления совпадают со скроллом карточек. Оба вида движения используют общие значения раздела `scroll`, зафиксированные при сборке. Камера переводится в экранные пиксели: 100 px прокрутки при скорости 1× меняют диаметр сферы на 100 px, в пределах дистанции камеры radius + 2 … 40. Исходное приближение камеры при появлении сохранено. Кадровые уравнения выполняются с частотой 60 Гц, чтобы скорость не менялась на мониторах 120 Гц.

Десять пользовательских снов циклически распределены по позициям. Изменён материал: вместо прямоугольных изображений — квадратные плоскости с круглой размытой маской. Размытие края, сила растворения и матовость берутся из раздела `gallery` в defaults сборки. Один общий видеоатлас декодируется и загружается в GPU только при появлении нового видеокадра. Матовость использует двухпроходное гауссово размытие атласа с выборками соседних пикселей и промежуточной текстурой двойного разрешения. Оно вычисляется один раз на видеокадр, а не отдельно для каждого кружка; края соседних снов изолированы. При нулевой матовости эти проходы отключены. Three.js 0.149.0 и GSAP 3.12.2 сохранены локально из исходной сборки; библиотеки загружаются только при первом открытии главной. Framer/React оболочка заменена подключением к существующему сайту.

Клик по сну и Enter/Space не открывают плеер. Перетаскивание, инерция, масштабирование и управление вращением стрелками сохранены. В скрытой вкладке галерея приостанавливает рендер, интро и атлас. В настройках она занимает первый слот нижнего блока: маленькая сфера рисуется только по кадрам общего видеоатласа, без отдельного постоянного RAF. Размытие выбирает из заранее выделенных буферов 320 × 128 (dock), 640 × 256 (обычный размер) и 1280 × 512 (сильное приближение). Выбор учитывает видимый размер сна и плотность пикселей, гистерезис исключает дрожание качества на границе. Во время полёта очищается только объединённая область предыдущего и текущего положения; буфер и камера остаются стабильными. Во время перелёта между страницами сохраняется кадровая анимация с ограничением WebGL-отрисовки до 60 кадров/с, в том числе на экранах 120–240 Гц. Системное ограничение движения отключает интро, автоматическое вращение и видео, сохраняя ручное управление. При недоступном WebGL показывается сетка постеров. Геометрия, зум, инерция и доступность локальных ресурсов проверяются тестами.
